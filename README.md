# Walmart Customer Segmentation using Machine Learning

## Project Overview

Developed a customer segmentation model using K-Means Clustering to group customers based on purchasing behavior. The project helps businesses understand different customer segments for targeted marketing and better decision-making.

## Dataset

- Retail customer dataset
- Customer purchase history
- Used for unsupervised machine learning

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Workflow

1. Data Cleaning
2. Exploratory Data Analysis (EDA)
3. Feature Selection
4. Data Scaling
5. K-Means Clustering
6. Elbow Method for Optimal Clusters
7. Cluster Analysis
8. Business Recommendations
